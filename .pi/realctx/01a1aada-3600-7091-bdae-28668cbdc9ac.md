`README.md` only contains usage examples and links to `docs/install.md` and `docs/architecture.md`. Both docs files are embedded at compile time in `src/util/handler.rs` and served via `doc_handler` at `GET /docs/{doc}` (plus `GET /README.md` via `index_handler`) with `Accept: text/html` content negotiation, so relative Markdown links work both on GitHub and on the web server.

ypb (`~/Workspaces/ypb`, Rust/axum, deployed at `https://pb.s-ton.top:4443` behind openresty; repo `github.com/st0nie/ypb`, personal project: commit as `Ston Jia <ston.jia@outlook.com>`, `git push origin master` over HTTPS works directly) serves `README.md` as the index page via `index_handler` in `src/util/handler.rs`: the `http://localhost:3000` origin in README examples is replaced at runtime with the public base URL, and browsers (`Accept: text/html`) get a GitHub-flavored Markdown HTML page (`markdown_page` rendered with `pulldown-cmark`, raw HTML escaped and unsafe link schemes sanitized, code blocks highlighted via highlight.js), matching `/{hash}.md` (`.markdown`, `.mdown`, `.mkd`), while curl gets plain text. Non-markdown extensions use `highlighted_page` with `pre code.hljs { overflow-x: visible; width: max-content; min-width: 100%; }` so horizontal scrolling happens at the browser viewport rather than only at the bottom of the `<code class="hljs">` element. Base URL comes from the `BaseUrl` extractor (`src/util/base_url.rs`): `--base-url`/`-b` if set, else `X-Forwarded-Proto` (default `http`) + `Host`. Keep README examples on `http://localhost:3000` so the substitution works. Router is built by `app()` in `src/main.rs` with tower `oneshot` integration tests (`cargo test`).

In `src/util/handler.rs`, `highlighted_page` renders a sticky unselectable `.line-numbers` gutter (`#L1`..`#L<n>` anchor links) alongside `<pre><code class="{resolved_language}">`, a full-width `#line-highlight` overlay supporting single-line (`#L10`) and Shift-click multi-line range (`#L10-L20`) URL hashes with automatic clipboard link copy and toast feedback, a floating `#copy-raw-btn` button to copy raw content, and `resolve_language` mapping `.lock` (detecting JSON/TOML/YAML lockfile content, defaulting to `toml`), `.conf`/`.cfg`/`.service` (`ini`), `.zsh`/`.env`/`pkgbuild` (`bash`), and `.jsonc`/`.jsonl` (`json`). Line selection can be cleared by re-clicking the active single line, pressing `Escape`, or clicking `#clear-line-btn` (`#L... ×`), and `#L...` links scroll with `max(140px, 28vh)` upper context (`scroll-margin-top` + `scrollToLine`).

Dependencies: `cargo upgrade` (cargo-edit) fails with 403 against the aliyun sparse mirror on this machine; bump deps with `cargo update` plus manual `Cargo.toml` edits, checking latest versions via `cargo update --dry-run --verbose` ("available:" notes).

Releases: GitHub releases tagged `vX.Y.Z`; `Cargo.toml` `version` is kept in sync with the tag. CI: `.github/workflows/release.yml` only triggers on `release: types: [created]`; publishing a draft fires `published`, not `created`, so drafts build no binaries. Create releases directly as non-draft: `gh release create vX.Y.Z --target master --title vX.Y.Z --latest --notes-file notes.md`. After a release, also run the Docker image workflow manually: `gh workflow run deploy-image.yml --ref master`.
